## 🚀 Déploiement sur GitHub Pages (GRATUIT)

### Étape 1 — Créer un compte GitHub
1. Allez sur **https://github.com**
2. Cliquez sur **"Sign up"** (Inscription)
3. Choisissez un nom d'utilisateur (ex : `jeanpaul-bognon`)
4. Entrez votre email et créez un mot de passe
5. Vérifiez votre email

---

### Étape 2 — Créer le dépôt
1. Une fois connecté, cliquez sur le **"+"** en haut à droite
2. Choisissez **"New repository"**
3. Nommez le dépôt : `ebookforge-ai`
4. Mettez-le en **Public** ✅
5. Cochez **"Add a README file"** ✅
6. Cliquez **"Create repository"**

---

### Étape 3 — Uploader les fichiers
1. Dans votre dépôt, cliquez sur **"uploading an existing file"**
2. Glissez-déposez ces 2 fichiers :
   - `index.html` ← le fichier principal de l'agent
   - `README.md` ← ce fichier
3. Cliquez sur **"Commit changes"**

---

### Étape 4 — Activer GitHub Pages
1. Dans votre dépôt, cliquez sur **"Settings"** (Paramètres)
2. Dans le menu gauche, cliquez sur **"Pages"**
3. Sous "Branch", sélectionnez **"main"**
4. Cliquez sur **"Save"**
5. Attendez 2-3 minutes ⏳

---

### Étape 5 — Votre lien permanent
Votre agent sera accessible à :
```
https://VOTRE-NOM-GITHUB.github.io/ebookforge-ai
```
**Exemple :** `https://jeanpaul-bognon.github.io/ebookforge-ai`

## 🔑 Configuration de la Clé API Anthropic

### Comment obtenir votre clé API (GRATUIT pour commencer)

1. Allez sur **https://console.anthropic.com**
2. Cliquez sur **"Sign Up"** et créez un compte
3. Vérifiez votre email
4. Dans le tableau de bord, cliquez sur **"API Keys"** (menu gauche)
5. Cliquez sur **"Create Key"**
6. Donnez un nom à la clé (ex : "EbookForge")
7. **Copiez la clé** — elle ressemble à : `sk-ant-api03-xxxx...`

> ⚠️ **Important :** Conservez cette clé précieusement. Elle ne sera plus affichée après.

### Intégrer la clé dans l'agent

**Option A — Directement dans le code (recommandé) :**
1. Ouvrez `index.html` avec Notepad ou VS Code
2. Trouvez cette ligne (ligne ~15) :
```javascript
const ANTHROPIC_API_KEY = "VOTRE_CLE_API_ICI";
```
3. Remplacez par votre vraie clé :
```javascript
const ANTHROPIC_API_KEY = "sk-ant-api03-xxxxxxxxxxxxxxxxxxxx";
```
4. Sauvegardez et re-uploadez sur GitHub

**Option B — Via l'interface de l'agent :**
1. Accédez à votre agent en ligne
2. Entrez le mot de passe (`ebookforge2025`)
3. Cliquez sur **⚙️ Configuration** dans le menu gauche
4. Collez votre clé API dans le champ prévu
5. Cliquez **"💾 Sauvegarder"**
