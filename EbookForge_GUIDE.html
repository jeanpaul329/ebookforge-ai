🔑 PARTIE 1 — Obtenir votre Clé API Anthropic
La clé API est le "moteur" de l'agent IA. Sans elle, l'agent ne peut pas générer d'ebooks. C'est gratuit pour commencer.
1
Créer un compte Anthropic
Ouvrez votre navigateur et allez sur :
https://console.anthropic.com
Cliquez sur "Sign Up" → Entrez votre email → Créez un mot de passe → Vérifiez votre email.
✅ Anthropic offre $5 de crédit gratuit à l'inscription = environ 30 à 50 ebooks longs !
2
Créer votre clé API
Une fois connecté à console.anthropic.com :
→ Cliquez sur "API Keys" dans le menu gauche
→ Cliquez sur le bouton "Create Key"
→ Donnez un nom à la clé : EbookForge
→ Cliquez sur "Create Key"
⚠️ Copiez immédiatement votre clé ! Elle ne sera affichée qu'une seule fois. Elle ressemble à :
sk-ant-api03-XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
Sauvegardez cette clé dans un fichier texte sur votre ordinateur.
3
Intégrer la clé dans l'agent
Ouvrez le fichier index.html avec Notepad (clic droit → Ouvrir avec → Notepad).

Utilisez Ctrl+H (Rechercher/Remplacer) et remplacez :
VOTRE_CLE_API_ICI
Par votre vraie clé (ex :)
sk-ant-api03-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Sauvegardez le fichier (Ctrl+S).
💡 Vous pouvez aussi entrer la clé directement dans l'interface de l'agent (⚙️ Configuration) sans modifier le fichier.
🚀 PARTIE 2 — Déployer sur GitHub Pages
GitHub Pages est un hébergement gratuit et permanent. Votre agent sera accessible 24h/24 depuis n'importe où dans le monde.
4
Créer un compte GitHub
Allez sur :
https://github.com
Cliquez sur "Sign up" → Entrez votre email → Choisissez un mot de passe → Choisissez un nom d'utilisateur (ex: jeanpaul-bognon) → Vérifiez votre email.
5
Créer un nouveau dépôt (Repository)
Une fois connecté sur GitHub :
→ Cliquez sur le "+" en haut à droite
→ Choisissez "New repository"
→ Dans "Repository name", tapez :
ebookforge-ai
→ Sélectionnez "Public" ✅ (obligatoire pour GitHub Pages gratuit)
→ Cochez "Add a README file"
→ Cliquez "Create repository"
6
Uploader les fichiers
Dans votre dépôt GitHub :
→ Cliquez sur "uploading an existing file" (ou "Add file" → "Upload files")
→ Faites glisser ces 2 fichiers dans la zone :
📄 index.html ← L'agent IA principal 📄 README.md ← La documentation
→ Descendez en bas de la page
→ Sous "Commit changes", cliquez sur le bouton vert "Commit changes"
💡 Si GitHub vous demande de renommer un fichier, assurez-vous que le fichier principal s'appelle exactement index.html
7
Activer GitHub Pages
Dans votre dépôt :
→ Cliquez sur "Settings" (icône engrenage en haut)
→ Dans le menu gauche, faites défiler jusqu'à "Pages"
→ Sous "Source" / "Branch", sélectionnez "main"
→ Laissez le dossier sur "/ (root)"
→ Cliquez "Save"
⏳ Attendez 2-5 minutes. GitHub va construire votre site.
