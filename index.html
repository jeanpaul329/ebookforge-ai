⚙️ Guide de Configuration

Suivez ces étapes pour activer la génération IA réelle de vos ebooks

1
🌐 Créer un compte Anthropic
Allez sur console.anthropic.com et créez un compte gratuit. Anthropic vous offre $5 de crédit pour commencer (≈ 20 ebooks).
https://console.anthropic.com
2
🔑 Obtenir votre clé API
Dans votre tableau de bord Anthropic :
→ Cliquez sur "API Keys" dans le menu gauche
→ Cliquez sur "Create Key"
→ Copiez la clé (commence par sk-ant-api03-...)
3
📝 Coller la clé dans le fichier
Ouvrez index.html avec un éditeur de texte (Notepad, VS Code). Trouvez la ligne et remplacez :
const ANTHROPIC_API_KEY = "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";
Par votre vraie clé :
const ANTHROPIC_API_KEY = "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";
4
🚀 Déployer sur GitHub Pages (Gratuit)
1. Créez un compte sur github.com
2. Créez un nouveau dépôt public nommé ebookforge-ai
3. Uploadez ce fichier index.html
4. Settings → Pages → Branch: main → Save
5. Votre lien : votre-nom.github.io/ebookforge-ai
5
